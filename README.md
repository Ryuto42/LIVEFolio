# LIVEFolio 🎵

**LIVEFolio** is a sophisticated web application designed for music enthusiasts to document, archive, and analyze their live concert experiences. Track setlists, venues, and artists in one elegant, responsive interface.

---

## ✨ Features

-   **Comprehensive Live Archive:** Effortlessly add, edit, and manage records of every live performance you attend.
-   **Setlist Management:** Record full setlists for each artist and look back at the songs performed.
-   **Spotify Integration:** Automatically fetches high-quality artist imagery via the Spotify API for a visually rich experience.
-   **Dynamic Dashboard:**
    -   **Next Live Countdown:** Stay excited with a real-time countdown to your next scheduled event.
    -   **Smart Grouping:** View upcoming shows, recent highlights, and artist-specific history.
-   **Powerful Analytics:**
    -   **Artist Rankings:** See which artists you've seen the most.
    -   **Venue History:** Identify your most frequented concert halls and live houses.
    -   **Track Stats:** Discover which songs you've actually heard "live" the most often across all recorded setlists.
-   **Advanced Search:** Instantly find events by artist, venue, event title, or even specific songs within setlists.
-   **Data Portability:** robust CSV Export/Import functionality for easy backups and data migration.
-   **Media Support:** Upload and store event photos (ticket stubs, venue shots, etc.) directly to Firebase Storage.
-   **Secure Access:** Multi-user support with Firebase Authentication and admin-only email whitelisting.

---

## 🛠️ Tech Stack

-   **Backend:** [Flask](https://flask.palletsprojects.com/) (Python)
-   **Database:** [Firebase Firestore](https://firebase.google.com/docs/firestore)
-   **Storage:** [Firebase Storage](https://firebase.google.com/docs/storage)
-   **Authentication:** [Firebase Authentication](https://firebase.google.com/docs/auth) (Google Login)
-   **API Integration:** [Spotify Web API](https://developer.spotify.com/documentation/web-api/)
-   **Frontend:** Semantic HTML5, Modern CSS3 (Vanilla), and Vanilla JavaScript for a fast, responsive UI.
